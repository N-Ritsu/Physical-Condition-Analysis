# 課題定義書

## 1. 現場の現状と課題
就労移行支援サービス支援員３人にアンケートを行った。

### 体調悪化サインの見落としリスク
- 支援員は毎朝目視で日報を確認しているが、単日の数値確認にとどまりがちである。  
- 利用者が不調を無理して隠してしまう場合や、1週間単位の緩やかな体調悪化トレンドに気づくのが難しい。

### 面談における客観的な振り返り材料の不足
- 定期面談やセルフチェックにおいて、過去の推移を本人と一緒に振り返るための、視覚的にわかりやすいデータが不足している。

### 福祉現場特有の制約（倫理とセキュリティ）
- 非医療性の担保: 支援員は医療職ではないため、システムが病気・障害の診断や断定的な因果関係を出すことは避けなければならない。
- 機密保持: ヘルスケア情報の外部送信・クラウドAIの利用は業界の規程上極めて難しく、ローカル環境で完結させる必要がある。

## 2. システムによる解決アプローチ（To-Be）
1. 客観的推移の可視化: 
   - 睡眠時間や気分の波、要因との関係性をグラフ化し、支援員と利用者が対話のベースとして使えるようにする。
2. 安心・安全な気づきAI:
   - クラウドにデータを送らない、ローカルLLMを採用。
   - 医学的断定を一切排除し、最近は〇〇な傾向があるようです。面談で様子を聞いてみませんか？といった対話補助のコメントのみを生成する。
