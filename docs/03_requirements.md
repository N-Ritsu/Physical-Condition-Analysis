# システム要件定義書

- プロジェクト名: 就労移行支援向け 体調・睡眠分析ダッシュボード
- 作成日: 2026年9月14日
- ステータス: 確定 / 開発中

## 1. システムの目的・背景
就労移行支援において、利用者が毎朝Googleフォームに入力している日報データを活用し、以下の2点を実現する。
- 単日の目視確認では気づきにくい、体調悪化のサインや緩やかな低下傾向をグラフ化により早期検知する。
- 定期面談やセルフチェックの場において、支援員と利用者が一緒に過去を振り返るための客観的な対話の材料を提供する。

## 2. 採用技術と選定理由
- データソース: Googleスプレッドシート（CSVエクスポート）
  - 選定理由: 現場の既存のGoogleフォーム運用を崩さずに連携させるため。
- データ処理・集計: Python 3.12以上, Pandas 3.x, NumPy 2.x
  - 選定理由: 日時データの正確なクレンジングや、相関・平均等の厳密な統計計算を行うため。最新の安定版を採用し、パフォーマンスと将来性を確保。
- UI・可視化: Streamlit（1.63系以上）, Plotly（7.x系）
  - 選定理由: 直感的なインタラクティブグラフ（マウスホバーで数値表示）とダッシュボードを迅速に構築するため。最新のイベント処理・バリデーション機能を活用可能。
- AI推論エンジン: ローカルLLM（Ollama環境）
  - 推奨モデル: Qwen3系（qwen3:8b）を主軸。日本語性能が高く、16GB程度のメモリで実用的に動作。
  - 代替候補: Llama系日本語特化モデル（Swallow 8B など）、または同等の軽量〜中型日本語対応モデル。
  - 選定理由: 福祉現場の機密保持規程を遵守し、個人情報や健康データを外部クラウドへ一切送信せずオンプレミスで完結させるため。Qwen2.5世代からQwen3世代へ移行し、日本語指示追従・考察生成の品質を向上。

## 3. 機能要件

### (1) データ処理・集計機能（Pandas）
- データの読み込み:
  - 日報CSVから、日付・体調・睡眠時間・入眠時間・起床時間・中途覚醒回数・気分等を取得する。
- データクレンジング:
  - 日付のパース、入眠時間の正規化。
  - 欠損値や異常値の適切な除外・補正処理。
- 統計計算:
  - 選択期間における各項目の平均値、中央値、最頻値の算出。
  - 2変数間の相関係数の算出およびクロス集計テーブルの作成。

### (2) 画面表示・可視化機能（Streamlit / Plotly）
手書きワイヤーフレームに基づき、直感的に操作できるダッシュボードを構築する。

- 期間フィルター機能:
  - 直近1週間・直近1ヶ月・全期間を選択・切り替え可能とする。
- インタラクティブな軸選択機能:
  - 縦軸の選択肢: 体調、睡眠時間、睡眠の質、入眠時間、起床時間、中途覚醒回数
  - 横軸: 日付

### (3) ローカルAI考察レポート機能（Ollama）
- 考察テキストの自動生成:
  - Pandasで算出した統計サマリーをプロンプトに入力し、グラフ直下に150〜200文字程度の考察文を出力する。
- 安全設計・ガードレール（現場ヒアリングに基づく制約）:
  - 医学的診断、病名判断、薬の服用に関する言及は一切出力させない。
  - 断定的な決めつけを排除し、「〜の傾向が見られます」「面談で〇〇について聞いてみると良いかもしれません」という対話補助のトーンに限定する。

## 4. 非機能要件

### (1) セキュリティ・プライバシー（最重要要件）
- 個人情報・体調データの外部送信は一切行わず、すべての処理をローカルPC（localhost）内で完結させる。

### (2) 動作環境
- 対応OS: Windows 10 / Windows 11（支援員の業務端末に準拠）
- 推奨ハードウェアスペック: メモリ（RAM）16GB程度（4bit量子化モデルが快適に動作する構成）

### (3) 保守性・品質
- PEP8に準拠したコードフォーマット（Ruff を主軸とし、必要に応じてBlack互換設定を使用）。
- データ計算モジュールに対する単体テスト（pytest）の作成。
